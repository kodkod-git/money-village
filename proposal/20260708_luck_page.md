행운 페이지를 만드려고 해. 메인 브랜치에서 새로운 브랜치 만들어서 진행해줘.
행운 페이지에는 가위바위보, 룰렛 색깔 맞추기, 주사위 눈금 맞추기 3가지 게임이 존재해야해.

0. 진입 방법
메인 페이지에 "머니빌리지 행운" 버튼 클릭
날짜/분반 선택하면 초기 설정 등장(은행/퀴즈와 동일)
초기 설정에는 가위바위보, 룰렛 색깔 맞추기, 주사위 눈금 맞추기 보상 배수 설정(default 가위바위보: 4배, 룰렛: 5배, 주사위: 7배)

1. 화면 구성
은행/퀴즈 화면과 동일하게 구성 (테마 색상은 빨강색, 오른쪽 상단에 위치한 "보상:-" 필요없음, 팀/개인 탭 필요없고 개인 뷰로 통일)
각 플레이어 버튼 클릭 시 게임 선택과, 배팅 금액 설정 화면(배팅 금액 설정은 예금 신청서 화면과 동일)
배팅 완료 버튼을 클릭 시 선택한 게임 화면 등장

2. 게임 룰
참가자 별 참가 회수에 제한, COOL DOWN도 필요없어
- 가위바위보
위에서는 가위, 바위, 보가 0.2초 간격으로 바뀜
아래에는 가위 바위 보 버튼이 3개의 버튼이 존재하고, 버튼 클릭 시 멈춤
이겼을 때만 보상 획득 지거나 비겼을 때는 획득 실패

- 룰렛 색깔 맞추기
위에는 빨강, 파랑, 노랑, 초록 4가지 색깔을 가진 원형 룰렛이 존재하며 빠르게 돌아감
아래에는 빨강, 파랑, 노랑, 초록 버튼이 존재하고, 버튼 클릭 시 멈춤
맞췄을 때만 보상 획득 못맞췄을 경우 획득 실패

- 주사위 눈금 맞추기
위에는 6가지 눈금을 가진 3D 주사위 존재하고 모든 눈금이 보이도록 돌아감
아래에는 멈춤 버튼이 존재하고, 버튼 클릭 시 멈춤
주사위 6이 나오면 보상 획득 안나올 경우 실패 

3. DB 설계
luck_history, luck_state 테이블 생성 (은행과 퀴즈와 동일)
luck_history: game_id, user_id, amount, matured_amount, luck_type(선택한 게임)
luck_state: game_id, 가위바위보 보상배수, 룰렛 보상배수, 주사위 보상배수
