"경제적 잠재력 테스트 보고서" 출력 기능뿐만 아니라, "경제적 유형 보고서" 출력 기능을 출력하려고 해.
현재 메인 페이지에 있는 "경제적 잠재력 테스트 보고서" 버튼을 "머니빌리지 경제적 유형 보고서"로 바꿔줘.
구글 시트를 참조하여 보고서를 출력할 수 있게하는 "경제적 잠재력 테스트 보고서" 출력 기능은 그대로 두면 돼.

탭(메뉴 이동)을 통해서 "경제적 유형 보고서" 또한 출력할 수 있게 만들어야 해.
"경제적 유형 보고서"는 사용자가 내용을 직접 입력해서 출력할 수 있도록 만들거야.
경제적 유형 보고서 탭 이동이 일어나면 4가지 입력 칸이 나와야 해.
입력 받아야할 내용은 다음과 같아.
1. 이름
2. 나이
3. EFTI (16가지 선택지 드롭다운)
4. 날짜 (default: 오늘 날짜)
입력완료 후 출력하기 버튼을 누르면, 곧 바로 출력 화면이 나오면 좋을 것 같아.
총 16가지 이미지가 있어.
EFTI에 따라 배경이 되는 이미지가 바뀌면 될 것 같아(경제적 잠재력 테스트 보고서와 비슷).
